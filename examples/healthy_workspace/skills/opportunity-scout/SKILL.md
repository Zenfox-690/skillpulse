# Opportunity Scout Skill

Use when scouting hackathon project opportunities or analyzing challenge criteria.
This skill discovers active hackathons and analyzes technical track requirements.

## MCP Tools Integration
When instructed, invoke `search_hackathons` to find open challenges and `audit_rules` to verify eligibility.
