Component & PRD Mapping

SkillPulseCLI skillpulse/cli.py
Implements prd.md > Unified CLI Interface

Handles user commands (scan, lint-skills, test-mcp, report), terminal ANSI color styling, and POSIX exit codes.

SkillScanner & Linter skillpulse/linter.py
Implements prd.md > Agent Skill Static Linter

Walks directories, isolates YAML frontmatter, validates schema rules SKILL001-SKILL005, and estimates token consumption.

MCPClientHarness skillpulse/mcp_tester.py
Implements prd.md > MCP 2025-11-25 Protocol Test

Manages subprocess stdio streams, JSON-RPC 2.0 handshake, 3.0s timeout guard, and tool inputSchema verification.

HTMLReporter skillpulse/reporter.py
Implements prd.md > Self-Contained HTML Report

Generates self-contained skillpulse-report.html with embedded CSS and zero external JavaScript library dependencies.
