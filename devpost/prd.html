Feature Specifications & Rules

The static linter inspects SKILL.md files against the Agent Skills specification standard:

Rule IDRequirementSeverityDescription
SKILL001 YAML Frontmatter Error Must begin and end with --- delimiters and contain valid YAML syntax.
SKILL002 Skill Name Error Attribute name required: 1-64 chars, lowercase alphanumeric + hyphens.
SKILL003 Description Error Attribute description required: clear action-oriented intent.
SKILL004 Trigger Guidance Warning Recommends explicit trigger phrases or activation conditions.
SKILL005 Token Budget Warning Flags skills exceeding 2,500 estimated tokens (~1.3 tokens/word) to prevent prompt bloat.

The dynamic test harness evaluates Model Context Protocol servers against the 2025-11-25 specification:

Rule IDProtocol StepSeverityValidation Target
MCP001 initialize handshake Error JSON-RPC 2.0 handshake returns protocol version 2025-11-25 and server info.
MCP002 ping heartbeat Error Responds to JSON-RPC ping request within 3.0s timeout.
MCP003 tools/list query Error Returns valid array of callable tool signatures.
MCP004 inputSchema validation Warning Validates each tool's inputSchema adheres to standard JSON Schema Draft 7/2020-12.
