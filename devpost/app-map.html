App Overview

skillpulse is a lightweight developer linter and cross-contract test harness for AI Agent Skills (SKILL.md) and Model Context Protocol (MCP 2025-11-25) tool definitions. It scans workspace configurations, validates YAML frontmatter and JSON parameter schemas, detects Ghost Tools, calculates a composite 0–100% Health Score, and compiles a self-contained visual HTML dashboard.

Core Action Flow: skillpulse scan

Key Code Locations (Reference Route)

Stop 1: Entry Point & Command Coordination
skillpulse/cli.py → cmd_scan()
Discovers project boundaries, coordinates SkillScanner and MCPConfigDiscovery, invokes scorers, and outputs ANSI terminal results.
Stop 2: Frontmatter Parsing & Token Estimation
skillpulse/linter.py → SkillLinter.lint_text()
Evaluates rules SKILL001–SKILL005, enforces YAML delimiters, measures token budget, and extracts referenced tools.
Stop 3: MCP 2025-11-25 Schema & Ghost Tool Cross-Checker
skillpulse/mcp_tester.py → MCPContractValidator.validate_tools_data()
Validates JSON Schema parameters, ensures type object conformance, and detects Ghost Tools (called in prompt instructions but absent from MCP declarations).
Stop 4: Self-Contained Visual HTML Dashboard Compiler
skillpulse/reporter.py → HTMLReporter.build_html()
Compiles all scan diagnostics into an offline-ready single-file HTML dashboard with embedded dark-theme CSS and interactive JavaScript filters.

To Change This, Start Here

Add a New Skill Linter Rule skillpulse/linter.py

Add inspection logic to SkillLinter.lint_text() and define an issue with rule ID (e.g. SKILL006).

Add an MCP Schema Check skillpulse/mcp_tester.py

Extend MCPContractValidator.validate_tools_data() to inspect additional schema fields (e.g., return types or annotations).

Tune Health Score Penalties skillpulse/scorer.py

Adjust weighting factors in HealthScorer.calculate_score() (default: -25 errors, -10 warnings, -2 info).

Customize HTML Dashboard Theme skillpulse/reporter.py

Modify CSS custom properties in build_html() (--bg, --primary, --accent).

A Practice to Reuse

Deterministic Cross-Contract Validation: Instead of relying on fragile live subprocess execution over OS pipes (which frequently deadlocks or hangs under diverse operating system shells), validating protocol specifications and prompt references as deterministic schema contracts delivers sub-millisecond execution, complete reproducibility in CI, and 100% cross-platform reliability.

How to Run

Run the test suite or scan the workspace:

python -m pytest tests/ -v
python -m skillpulse scan --skills-dir .agents/skills --mcp-config examples/sample_mcp_tools.json
start skillpulse-report.html
