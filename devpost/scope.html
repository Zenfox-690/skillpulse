skillpulse

Open-source Linter, Test Harness, and Diagnostics Suite for AI Agent Skills & MCP (2025-11-25) Servers

✓ Scope Status: Approved

The Unique Kernel

Unified Dual-Ecosystem Validation: Linting both human-authored Agent Skills (SKILL.md) and protocol-driven Model Context Protocol (MCP 2025-11-25) servers in a single high-speed CLI run (<500ms), outputting actionable diagnostics, token cost estimation, and a self-contained visual dashboard.

The Core Loop Architecture

Proof of Concept Boundary Explorer

  • ✓
    SKILL.md Static Linter: Validates YAML frontmatter syntax, required name and description, trigger phrasing, and token budget estimation.
  • ✓

  • ✓
    Interactive Standalone HTML Reporter: Generates self-contained skillpulse-report.html with visual charts, error badges, and 1-click remediation guides.
  • ✓
    Multi-Target CLI Commands: skillpulse scan, skillpulse lint-skills, skillpulse test-mcp, and skillpulse report.
  • ✓
    Automated Pytest Suite: Comprehensive unit testing for fast, reproducible CI execution.
